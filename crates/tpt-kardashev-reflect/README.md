# tpt-kardashev-reflect

Verified self-modification: linear-invariant containment certificates, a checker and an audited update gate.

**Status:** Phase 0 scaffold. No public API yet.

## Features

- `std` (default): links the standard library.
- `alloc`: enables heap-allocating APIs. Core is `no_std`.

## What it does not model

Open research risk. Only linear bounds are supported. Optional adapters to tpt-formal and tpt-solver are later.
